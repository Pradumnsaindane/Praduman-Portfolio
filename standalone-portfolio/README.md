# Pradumn Bharat Saindane — Portfolio

Single-file site: `index.html` (HTML + CSS + vanilla JS, no build step, no dependencies).

## Run it
Open `index.html` directly in a browser, or serve the folder with any static server /
your IDE's Live Server extension for live-reload while editing.

## Before you publish
Set these two constants near the top of the `<script>` block in `index.html`:

```js
const RESUME_URL   = "";  // your résumé link (PDF / Drive URL)
const LINKEDIN_URL = "";  // your LinkedIn profile URL
```

If you have real roles to show, add them to the `EXPERIENCE` array the same way
`PROJECTS` and `STACK` are structured.
